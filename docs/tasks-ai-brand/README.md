# tasks-ai Brand Assets v3 · Bitmap

**Símbolo aprobado:** zorro con guiño pícaro. Paquete sin SVG, construido desde la imagen generada aprobada de 1254 × 1254 px.

- `master/fox-original-black-1254.png`: **fuente fiel original** sobre negro, sin retoque.
- `master/fox-transparent-native.png`: extracción de fondo para uso transparente (verificar halos).
- `logos/`: símbolo PNG y composiciones tipográficas horizontales/verticales.
- `app-icons/`: iconos PNG dark/light en múltiples tamaños.
- `favicons/`: ICO, PNG, Apple touch y PWA.
- `design/`: tokens CSS/JSON y guía visual.
- `AGENT-INTEGRATION.md`: pasos para el agente.

Nota: para conservar fidelidad total al arte aprobado, usar el original sobre negro; la transparencia implica segmentación automática, y no es perfecta en los brillos periféricos.
